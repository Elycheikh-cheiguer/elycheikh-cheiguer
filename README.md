# Elycheikh Cheiguer portfolio

This is a simple static HTML, CSS and JavaScript portfolio. No Node.js, build
step, or package installation is needed.

Open `index.html` directly in a browser. Bootstrap and the chosen typefaces
are loaded from their CDNs, so those styling details require an internet
connection. Use the links in the sidebar to move between the six pages:

- `index.html` — home
- `about.html` — about
- `journey.html` — education and experience
- `projects.html` — projects
- `skills.html` — skills
- `contact.html` — contact

Edit each page in its HTML file, site-wide appearance in `style.css`, and
language and interactions in `script.js`. Images and CV files are in `assets/`.
